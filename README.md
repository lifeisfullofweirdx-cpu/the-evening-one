# The Evening One - Steven Mod

## Overview
The Evening One is a Minecraft Bedrock/PE companion mod featuring **Steven**, a mysterious stalker companion that protects and aids players.

## Features

### Core Mechanics
- **Companion Entity**: Steven spawns alongside you and provides protection and support
- **Stalking Behavior**: Occasionally stalks players (configurable)
- **Individual Instances**: Each player gets their own Steven
- **Bond System**: Build relationships through interaction
- **Pet System**: Make Steven follow, sit, and obey commands

### Interaction Methods
- **The Mic (32 Interactive Choices)**:
  - Dialogue system with 32 unique speech options
  - Steven remembers all interactions
  - Responses based on bond strength
  - Examples: "Hello Steven", "Protect me", "Follow me", "Help me", etc.

### Customization
- **Naming**: Use name tags or direct interaction
- **Armor**: Equip Steven with armor
- **Leads**: Put Steven on a lead for direct control
- **Appearance**: Tall entity with black fur, hollow white eyes, cat-like limbs

### Special Behaviors
- **Protection**: Fights enemies that attack the player
- **Communication**: Verbal and physical interactions
- **Theft Tendency**: Occasionally steals items from player chests
- **Feeding**: Give items to feed and bond with Steven
- **Loyalty**: Once bonded, remains loyal and devoted

### Items
- **The Mic**: Automatically given upon spawn, cannot be lost on death
  - 32 dialogue options
  - Persistent in inventory
  - Enchanted appearance

- **Steven Spawn Egg**: Available in creative inventory
  - Spawns a new Steven
  - Stackable (up to 64)

## Steven's Appearance
- **Height**: 2.2 blocks tall
- **Fur**: Black
- **Eyes**: Hollow white
- **Limbs**: Cat-like
- **Posture**: Stands on two legs
- **Personality**: Kind, loyal, easy to bond with

## Default Name
The default name is "Steven", but can be customized with name tags or commands.

## Bond System
Bond levels affect:
- Dialogue responses
- Protection behavior intensity
- Willingness to help
- Loyalty duration
- Special interactions

## Installation
1. Place the `behavior_packs/evening_one` folder in your world's behavior pack directory
2. Place the `resource_packs/evening_one` folder in your world's resource pack directory
3. Enable both packs in world settings
4. The Mic will be automatically given on spawn
